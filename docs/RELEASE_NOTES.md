# StudyApp v1.0.0-beta.1

## Tester build

- Faster first dashboard load: inactive features no longer all start at login.
- A short, skippable first-use guide explains courses, AI Studio, and practice.
- Light mode is the default for fresh installs.
- Improved network timeout handling and Android internet access.
- Deployment fixes for shared PostgreSQL, JWT authentication, and persistent application keys.

## Before installing

- Android device only.
- Install from the GitHub Release asset named `app-release.apk`.
- If Android warns about an unknown source, allow installation for the browser or file manager used to download the file.
- Use a stable internet connection and create a test account with an email you can access.

## Known pilot limitation

This beta is for invited testing. Do not upload confidential school records or sensitive personal information. Report problems through the feedback form or GitHub issue template.
